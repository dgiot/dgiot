## Обзор

dgaiot — высокопроизводительный IoT-движок агрегации на Erlang/OTP.

- Shadow Device (gen_statem)
- DLAS Ontology (Data·Logic·Action·Security)
- FDE Pipeline (Model→Ontology→Device→TimeSeries→Rules→Dashboard)
