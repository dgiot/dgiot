# AI生成代码审查清单

## 基础检查
✅ 1. 代码风格是否符合项目规范  
✅ 2. 模块头注释和函数-spec是否完整  
✅ 3. 错误处理路径是否完备  

## 功能验证
✅ 1. 是否覆盖所有需求场景  
✅ 2. 边界条件是否处理妥当  
✅ 3. 性能指标是否达标  

## 安全审查
✅ 1. 输入参数是否严格校验  
✅ 2. 是否存在潜在资源泄漏  
✅ 3. 敏感数据是否安全处理  

## 集成测试
✅ 1. 是否影响现有功能  
✅ 2. 接口兼容性是否保证  
✅ 3. 日志输出是否规范  

## 优化建议
🔧 1. 是否存在更优实现方案  
🔧 2. 代码是否可读性优化  
🔧 3. 是否有性能提升空间
