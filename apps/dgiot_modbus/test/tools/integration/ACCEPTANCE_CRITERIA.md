# RegisterByPort端口注册功能验收标准

## 概述

本文档定义了RegisterByPort端口注册功能的验收标准，确保功能正确性和质量。

## 1. 核心验收标准

### 1.1 设备注册成功标准

**必须满足以下所有条件**：

#### ✅ 标准1：设备地址生成正确
- **要求**：设备地址 = 注册报文 + "-" + 服务器端口
- **示例**：`"wrj_dm-zqy" + "-" + "20000" = "wrj_dm-zqy-20000"`
- **验证方法**：检查设备信息中的`devaddr`字段

#### ✅ 标准2：设备成功保存到数据库
- **要求**：设备信息在DG-IoT平台中可查询
- **验证方法**：使用`dgiot_device:lookup(DeviceId)`查询设备
- **预期结果**：返回`{ok, Device}`，设备信息完整

#### ✅ 标准3：设备信息完整
- **要求**：设备包含必要的属性字段
- **必须包含的字段**：
  - `devaddr`：设备地址（必须符合标准1）
  - `productid`：产品ID
  - `status`：设备状态（应为`true`）
  - `isEnable`：设备启用状态（应为`true`）
  - `devicesecret`：设备密钥（自动生成）
  - `time`：注册时间戳

### 3.2 手动验证命令

```erlang
% 验证设备注册
DeviceAddr = <<"wrj_dm-zqy-20000">>,
ProductId = <<"feeb43bffb">>,
DeviceId = dgiot_parse_id:get_deviceid(ProductId, DeviceAddr),

case dgiot_device:lookup(DeviceId) of
    {ok, Device} ->
        % 检查设备地址
        DevAddr = maps:get(<<"devaddr">>, Device),
        % 检查设备状态
        Status = maps:get(<<"status">>, Device),
        % 检查启用状态
        IsEnable = maps:get(<<"isEnable">>, Device),
        % 输出验证结果
        io:format("设备验证结果:~n"),
        io:format("  设备地址: ~p (预期: ~p)~n", [DevAddr, DeviceAddr]),
        io:format("  设备状态: ~p (预期: true)~n", [Status]),
        io:format("  启用状态: ~p (预期: true)~n", [IsEnable]);
    {error, not_found} ->
        io:format("❌ 设备未找到~n");
    {error, Reason} ->
        io:format("❌ 设备查询错误: ~p~n", [Reason])
end.
```
