# 无人机工位管理系统设计文档

## 系统概述

根据用户反馈，重新设计了无人机自动化生产线的工位管理系统。系统采用进程化的工位管理架构，每个工位独立运行一个Erlang进程，通过心跳机制进行状态监控和反注册。

## 核心模块

### 1. 工位注册表 (`station_registry.erl`)

#### 主要功能
- 工位进程的创建和管理
- 工位状态的维护和查询
- 工位状态广播机制
- 工位配置管理

#### 关键特性
- **进程化架构**: 每个工位运行独立Erlang进程
- **注册名规范**: 按工位ID命名进程（如`station_1`、`station_magnetic`）
- **状态广播**: 工位状态变化时广播给其他工位
- **配置驱动**: 从配置表加载工位信息

### 2. 心跳管理器 (`heartbeat_manager.erl`)

#### 主要功能
- 工位心跳监控
- 超时检测和状态标记
- 非活跃工位清理
- 反注册机制

#### 心跳机制
- **心跳间隔**: 10秒
- **心跳超时**: 30秒（标记为离线）
- **清理超时**: 120秒（执行反注册）
- **状态分级**: 在线 → 警告 → 离线 → 清理

#### 反注册策略
1. **心跳超时检测**: 30秒无心跳标记为离线
2. **清理检查**: 120秒离线状态触发清理
3. **反注册流程**: 
   - 停止工位进程
   - 从注册表移除
   - 广播工位离线状态
4. **覆盖式注册**: 新设备注册时覆盖旧注册

### 3. 设备处理器更新

#### 磁航向处理器 (`magnetic_handler.erl`)
- 更新为处理地测口数据的一部分
- 支持EB90协议解析
- 磁航向工位ID: 20

#### 其他处理器
- **治具处理器**: 处理治具设备注册和状态管理
- **舵面处理器**: 处理舵面传感器数据
- **无人机处理器**: 处理无人机设备和控制命令

## 工作流程

### 1. 设备注册流程
```
1. 设备发送注册报文（如："wrj_dm_zhj:192.168.100.10"）
2. TCP工作器识别设备类型
3. 调用相应处理器解析设备信息
4. 根据设备类型和传感器地址确定工位ID
5. 向工位注册表注册工位
6. 启动工位进程（如已存在则复用）
7. 启动心跳监控
8. 广播工位在线状态
```

### 2. 心跳监控流程
```
1. 心跳管理器每10秒检查所有工位
2. 更新最近心跳时间
3. 检测超时工位（30秒无心跳）
4. 标记超时工位为离线
5. 广播工位状态变化
6. 定期清理离线工位（120秒）
```

### 3. 工位状态广播
```
1. 工位状态变化时（注册/注销/离线）
2. 注册表向所有其他工位进程发送状态更新
3. 工位进程接收并处理状态更新
4. 实现工位间的状态同步
```

## 关键技术特性

### 1. 进程管理
- **独立进程**: 每个工位独立运行，互不干扰
- **进程注册**: 使用原子名称注册，便于查找和管理
- **进程监控**: 通过心跳机制监控进程健康状态

### 2. 状态同步
- **实时广播**: 工位状态变化实时通知其他工位
- **状态一致性**: 所有工位保持一致的全局状态视图
- **故障隔离**: 单个工位故障不影响其他工位

### 3. 资源管理
- **自动清理**: 超时工位自动反注册和清理
- **资源回收**: 释放不再使用的进程资源
- **内存优化**: 按需创建和销毁工位进程

### 4. 可扩展性
- **配置驱动**: 新增工位只需更新配置表
- **模块化设计**: 易于添加新的设备类型
- **协议扩展**: 支持多种通信协议

## 系统优势

### 1. 可靠性
- 心跳机制确保工位状态实时监控
- 自动反注册防止资源泄漏
- 故障隔离提高系统稳定性

### 2. 可维护性
- 清晰的模块划分和接口定义
- 配置驱动的工位管理
- 详细的日志和监控信息

### 3. 性能
- 进程化架构支持并发处理
- 智能状态广播减少不必要的通信
- 高效的心跳检测算法

### 4. 灵活性
- 支持多种设备类型和协议
- 易于扩展新的工位配置
- 可配置的心跳和清理参数

## 部署建议

### 1. 启动顺序
```
1. 启动工位注册表: station_registry:start_link()
2. 启动心跳管理器: heartbeat_manager:start_link()
3. 启动TCP工作器: dgiot_uav_tcp_worker
4. 启动设备处理器
```

### 2. 监控指标
- 工位在线/离线数量
- 心跳超时率
- 工位注册/注销频率
- 系统资源使用情况

### 3. 故障处理
- 工位进程崩溃自动重启
- 心跳超时自动标记和清理
- 网络中断的容错处理

## 总结

重新设计的工位管理系统解决了原始架构中的多个问题：
1. **磁航向处理**: 正确作为地测口数据的一部分
2. **进程化管理**: 每个工位独立进程，便于管理
3. **心跳机制**: 实现自动反注册和资源清理
4. **状态广播**: 工位间状态实时同步
5. **配置驱动**: 灵活的工位配置管理

系统能够更好地支持无人机自动化生产线的复杂场景，提供可靠、高效、可扩展的工位管理解决方案。
