## 数据流向

### 设备数据上报

```
治具/PLC/无人机
    │ TCP/UDP
    ▼
DGIOT (20000)
    │ 协议解析
    ▼
业务处理
    │ 数据存储
    ▼
Parse Server / TDengine
```

### MES数据上报

```
DGIOT业务层
    │ HTTP POST
    ▼
Nginx (80)
    │ Proxy Pass
    ▼
MES模拟器 (801)
    │ 内存存储
    ▼
测试结果数据库
```

## 启动顺序

```
1. 启动 integrated_production_line.py
        │
        ▼
2. 清理冲突进程
        │
        ▼
3. 绑定IP地址
        │
        ▼
4. 启动 PLC模拟器 (502端口)
        │
        ▼
5. 启动 治具模拟器 (连接DGIOT 20000)
        │
        ▼
6. 启动 无人机模拟器 (多播通信)
        │
        ▼
7. 执行测试用例
        │
        ▼
8. 设备上线 → 测试执行 → 数据采集
        │
        ▼
9. MES数据上报 (通过Nginx代理)
        │
        ▼
10. 闭环验证
        │
        ▼
11. 生成测试报告
```

## 测试场景

### 场景1: 简化测试流程

```
上料台 → 磁航向 → 总测2 → 总测1
```

### 场景2: 完整产线

```
磁航向 → 总测 → 动力检测 → 拷机 → 桁架
```

### 场景3: 所有产线

```
4条路径依次执行:
- 产线A路径1
- 产线A路径2
- 产线B路径1
- 产线B路径2
```
