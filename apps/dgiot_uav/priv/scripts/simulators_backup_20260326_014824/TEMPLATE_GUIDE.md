# Word模板使用说明

## 模板变量

报告生成器会替换Word模板中的以下变量:

### 基本信息

| 变量 | 说明 | 示例 |
|------|------|------|
| `{无人机编号}` | 无人机设备名称 | UAV-001 |
| `{设备地址}` | 设备地址 | 10007-1500 |
| `{产品名称}` | 产品名称 | 超近距无人机 |
| `{工位名称}` | 工位名称 | 总测工位1 |
| `{测试日期}` | 测试日期 | 2024年03月21日 |
| `{测试时间}` | 测试时间 | 14:30:00 |
| `{测试日期时间}` | 完整日期时间 | 2024年03月21日 14:30:00 |

### 测试结果

| 变量 | 说明 | 示例 |
|------|------|------|
| `{测试结果}` | 整体测试结果 | 通过 |
| `{测试项总数}` | 测试项数量 | 10 |
| `{通过项数}` | 通过的项数 | 9 |
| `{失败项数}` | 失败的项数 | 1 |
| `{通过率}` | 通过率 | 90.00% |

### 遥测数据

| 变量 | 说明 | 示例 |
|------|------|------|
| `{电压}` | 电池电压 | 24.5V |
| `{电流}` | 电池电流 | 1.2A |
| `{温度}` | 温度 | 35.5°C |
| `{气压}` | 气压 | 1013hPa |
| `{湿度}` | 湿度 | 65% |

### 测试过程

| 变量 | 说明 | 示例 |
|------|------|------|
| `{测试过程记录数}` | td子表记录数 | 15 |

### 表格占位符

| 变量 | 说明 |
|------|------|
| `{测试项表格}` | 测试项详情表格(4列: 序号,测试项目,测试标准,测试结果) |
| `{测试过程表格}` | 测试过程数据表格(4列: 序号,记录时间,测试步骤,数据内容) |

### 完整Word模板

创建一个Word文档,包含以下内容:

1. **标题**: "超近距无人机测试报告"
2. **副标题**: "UAV Automated Test Report"
3. **基本信息表格**: 包含所有基本信息变量
4. **测试结果**: 显示测试统计
5. **测试项表格**: 使用`{测试项表格}`占位符
6. **遥测数据**: 显示实时数据
7. **测试过程表格**: 使用`{测试过程表格}`占位符

## 模板创建步骤

### 使用Microsoft Word创建模板

1. 打开Microsoft Word
2. 创建新文档
3. 设置页面布局(建议A4)
4. 添加标题和副标题
5. 创建基本信息表格
6. 插入测试结果信息
7. 插入测试项表格(先创建一个4列表格作为占位符)
8. 添加遥测数据部分
9. 插入测试过程表格(先创建一个4列表格作为占位符)
10. 替换静态内容为变量占位符

## 数据流程

```
1. 无人机上线并绑定工位
   ↓
2. 通过工位查询测试项配置
   ↓
3. 自动下发测试指令
   ↓
4. 测试数据汇聚到td子表
   ↓
5. 测试结果保存到Device.content
   ↓
6. 调用报告生成API
   ↓
7. 从Parse获取数据:
   - Device.content.test_result
   - 工位查询的测试项
   - td子表的测试过程
   - TDengine的遥测数据
   ↓
8. 构建模板变量
   ↓
9. 加载Word模板
   ↓
10. 替换模板变量
   ↓
11. 保存为Word报告
   ↓
12. 可选转换为PDF
   ↓
13. 返回URL给MES
```

## 模板变量替换规则

### 文本替换

所有段落和表格单元格中的文本都会被替换:

```doc
无人机编号: {无人机编号}
↓
无人机编号: UAV-001
```

### 表格替换

表格占位符会被完整的数据表格替换:

```doc
{测试项表格}
↓
┌────┬──────────┬──────────┬──────────┐
│序号│测试项目  │测试标准  │测试结果  │
├────┼──────────┼──────────┼──────────┤
│1   │外观检查  │无异常    │通过      │
│2   │电压测量  │24V±0.5V  │通过      │
└────┴──────────┴──────────┴──────────┘
```

## 注意事项

1. **模板文件必须存在**: 如果模板不存在,会使用默认方式生成报告
2. **变量格式**: 变量必须使用花括号,如`{无人机编号}`
3. **表格占位符**: 表格占位符会完全替换整个表格
4. **编码问题**: 模板文件使用UTF-8编码
5. **变量不存在**: 如果变量不存在,会被替换为空字符串

## 故障排除

### 模板找不到

```bash
# 检查模板文件
ls -la /root/gitee/dgiot/apps/dgiot_uav/priv/scripts/test_report_template.docx

# 如果不存在,创建一个空模板
touch /root/gitee/dgiot/apps/dgiot_uav/priv/scripts/test_report_template.docx
```

### 变量没有替换

1. 检查变量格式是否正确(使用花括号)
2. 检查变量名是否与代码中定义的一致
3. 查看日志输出,确认变量是否被构建

### 表格没有替换

1. 确保表格占位符在段落中,不是在表格单元格中
2. 检查数据是否正确获取
3. 查看日志,确认数据是否为空

## 高级用法
