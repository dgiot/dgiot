## 数据流向

### 1. 设备数据上报流程

```
治具/PLC/无人机 → TCP/UDP → DGIOT(20000) → 协议解析 → 业务处理 → 数据存储
```

### 2. MES数据上报流程

```
DGIOT业务层 → HTTP POST → Nginx(80) → Proxy Pass → MES模拟器(801) → 内存存储
```

### 3. 测试流程

```
启动脚本 → 启动模拟器 → 设备上线 → 工位测试 → 数据采集 → MES上报 → 闭环验证
```

## 一键启动工作流

```bash
python3 integrated_production_line.py --verify --save-report
```

**执行步骤**:

1. **初始化阶段**
   - 清理冲突进程
   - 绑定必要IP地址
   - 验证网络配置

2. **启动模拟器**
   - PLC模拟器 (127.0.0.1:502)
   - 治具模拟器 (连接DGIOT 20000)
   - 无人机模拟器 (多播226.0.0.80)

3. **执行测试用例**
   - 按工位顺序启动设备
   - 执行PLC 7步握手
   - 模拟测试执行
   - 采集测试数据

4. **数据上报**
   - 设备状态上报
   - 测试结果上报
   - MES数据上报

5. **闭环验证**
   - 工位状态检查
   - 设备监控器检查
   - 验证结果汇总

6. **生成报告**
   - 保存JSON测试报告
   - 统计测试数据
   - 输出验证结果

## 核心配置

### 固化配置（无需修改）

- **工位IP**: 192.168.100.45-52
- **PLC IP**: 192.168.100.40/20
- **MES IP**: 172.1.2.222
- **DGIOT端口**: 20000
- **PLC端口**: 502
- **MES端口**: 801（通过nginx代理80）

### 动态配置（可选）

- 循环次数: `--cycles N`
- 启用MES: `--enable-mes`
- 闭环验证: `--verify`
- 保存报告: `--save-report`
