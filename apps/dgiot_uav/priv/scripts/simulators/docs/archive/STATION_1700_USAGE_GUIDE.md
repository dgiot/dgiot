## 网络配置要求

### 工控机网络配置

工控机需要绑定以下IP地址：

```bash
# 绑定工控机所有IP
for ip in 192.168.100.{20,21,23,35,36,40,45..52}; do
    ip addr add $ip/24 dev eth0
done
```

**关键IP地址**:
- `192.168.100.100` - 工控机自身（DG-IoT平台运行在此）
- `192.168.100.20` - 磁航向PLC
- `192.168.100.21` - 磁航向工位治具IP
- `192.168.100.23` - 扫码枪IP

### DG-IoT平台配置

DG-IoT平台需要监听以下端口：

- `20000` - TCP Server（设备连接端口）
- `1883` - MQTT Broker
- `18083` - HTTP API
- `502` - Modbus TCP Server（可选）

### 网络连接测试

执行测试前，先验证网络连接：

```bash
# 测试工控机到DG-IoT平台连接
ping -c 3 192.168.100.100

# 测试DG-IoT平台端口
telnet 192.168.100.100 20000
```

## 常见问题

### Q1: 连接失败 - 无法连接到DG-IoT平台

**错误信息**:
```
Connection refused: [Errno 111] Connection refused
```

**解决方案**:
1. 检查DG-IoT平台是否运行：
   ```bash
   systemctl status dgiot
   # 或
   ps aux | grep emqx
   ```

2. 检查端口是否监听：
   ```bash
   netstat -tlnp | grep 20000
   ```

3. 检查防火墙规则：
   ```bash
   iptables -L -n | grep 20000
   ```

### Q2: 测试超时 - 步骤执行时间过长

**错误信息**:
```
TimeoutError: 步骤执行超时
```

**解决方案**:
1. 检查PLC通信是否正常
2. 检查设备响应速度
3. 调整测试超时参数

### Q3: 测试记录未生成

**可能原因**:
1. 目录权限不足
2. 磁盘空间不足

**解决方案**:
1. 检查目录权限：
   ```bash
   ls -ld apps/dgiot_uav/priv/scripts/simulators/test_records/
   ```

2. 检查磁盘空间：
   ```bash
   df -h
   ```
