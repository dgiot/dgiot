## 测试框架设计

### 基础类设计

所有工位测试脚本都基于以下基础类:

```python
# 1. TestRecord - 测试记录管理类
class TestRecord:
    - start(): 开始测试
    - end(): 结束测试
    - step_start(): 测试步骤开始
    - step_end(): 测试步骤结束
    - log(): 记录日志
    - save(): 保存测试记录
    - _generate_markdown_report(): 生成Markdown报告

# 2. BaseStationScenario - 工位场景基类
class BaseStationScenario:
    - setup(): 测试环境准备
    - run(): 执行完整测试场景
    - run_step_X(): 执行测试步骤X
```

### 测试记录存储

所有测试记录存储在:
```

```

1. **JSON格式**: 用于程序处理和数据分析
