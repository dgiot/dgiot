## 设备详细说明

### 1. 地测口（无人机）

| 配置项 | 值 |
|--------|-----|
| **设备类型** | 地测口（无人机数据接口） |
| **设备ID** | wrj_dicekou |
| **产品ID** | 6235befb62 |
| **源端口** | 10007 |
| **目标端口** | 20000 (DG-IoT TCP Server) |
| **设备IP** | 动态IP（随工位变化） |
| **IP类型** | 动态IP |
| **移动性** | 移动设备 |
| **是否舵面设备** | 否 |

**功能说明**：
- 无人机通过地测口连接到DG-IoT平台
- 接收EB90协议数据（遥控、遥测、载荷等）
- 汇聚所有设备数据并存储到无人机物模型
- 作为测试流程中的被测试对象

**数据流**：
```
无人机 → 地测口(10007) → 20000端口 → DG-IoT平台
                                        ↓
                                    EB90协议数据解析
                                        ↓
                                    存储到无人机物模型
                                        ↓
                                    触发测试流程
```

**在磁航向工位的IP**：
- 当无人机在磁航向工位时，设备IP为工位治具IP
- 磁航向工位治具IP：192.168.100.21
- 系统通过治具IP识别为磁航向工位设备
- 自动绑定到1700工位

    ↓

    ↓
开始自动化测试流程
