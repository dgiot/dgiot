# 无人机测试产线 - 一键式端到端测试文档

## 概述

这个测试脚本提供了一套完整的无人机产线测试解决方案，每个工位都有独立的测试场景，支持单个工位测试和完整产线测试。

## 设计理念

1. **每个工位一个场景**：每个工位都有明确的测试步骤和预期结果
2. **端口即设备类型**：通过端口号自动识别设备类型
3. **端到端测试**：从扫码开始到报告生成的完整流程
4. **噪音全程监控**：1700工位全程监控产线噪音
5. **详细测试报告**：生成JSON和HTML格式的测试报告

## 使用方法

### 1. 查看所有工位

```bash
cd /root/gitee/dgiot/apps/dgiot_uav/priv/scripts/simulators
python3 one_click_production_test.py --list-stations
```

### 2. 查看单个工位详情

```bash
# 查看总测工位详情
python3 one_click_production_test.py --station-detail 1500

# 查看磁航向工位详情
python3 one_click_production_test.py --station-detail 1200
```

### 3. 测试单个工位

```bash
# 测试磁航向工位
python3 one_click_production_test.py --station 1200

# 测试总测工位
python3 one_click_production_test.py --station 1500

# 测试拷机工位
python3 one_click_production_test.py --station 1600

# 测试桁架工位
python3 one_click_production_test.py --station 1100
```

### 4. 测试完整产线

```bash
# 测试完整产线（包含告警监控）
python3 one_click_production_test.py --full-line

# 测试完整产线并生成HTML报告
python3 one_click_production_test.py --full-line --generate-report
```

### 5. 指定日志目录

```bash
# 使用自定义日志目录
python3 one_click_production_test.py --full-line --log-dir /tmp/test_logs
```

## 测试流程

### 完整产线测试流程

```
1. 启动告警监控 (1700工位)
   ├── 连接2个噪音传感器
   ├── 设置告警阈值（警告75dB，严重85dB）
   └── 开始实时监控

2. 磁航向工位测试 (1200工位)
   ├── 步骤1: 扫码获取设备编码 (5秒)
   ├── 步骤2: 磁航向校准测试 (30秒)
   ├── 步骤3: 磁场精度检测 (20秒)
   └── 步骤4: 磁偏补偿测试 (25秒)

3. 总测工位测试 (1500工位)
   ├── 步骤1: 备检并获取编码 (5秒)
   ├── 步骤2: 机身静态测试前检查 (10秒)
   ├── 步骤3: 机身及螺旋桨安装情况检查 (15秒)
   ├── 步骤4: 电压测量检查 (10秒)
   ├── 步骤5: 链路功能检查 (20秒)
   ├── 步骤6: 上电参数检查 (15秒)
   ├── 步骤7: 夜航灯测试 (10秒)
   ├── 步骤8: 气压高度检测 (15秒)
   ├── 步骤9: 系统电磁兼容性功能检查 (20秒)
   └── 步骤10: 航线加载及载荷功能检查 (30秒)

4. 拷机工位测试 (1600工位)
   ├── 步骤1: 拷机前检查 (10秒)
   ├── 步骤2: 舵面数据采集测试 (120秒)
   ├── 步骤3: 导引头功能测试 (30秒)
   └── 步骤4: 拷机时长验证 (10秒)

5. 桁架工位测试 (1100工位)
   ├── 步骤1: 桁架机械手测试 (20秒)
   ├── 步骤2: 舵面机械臂测试 (20秒)
   └── 步骤3: 导引头功能验证 (30秒)

6. 停止告警监控
   └── 生成告警报告

7. 生成测试报告
   ├── JSON格式报告
   └── HTML格式报告
```

## 故障排查

### 问题1：连接DG-IoT服务器失败

**错误信息**：`连接DG-IoT服务器失败`

**解决方案**：
1. 检查DG-IoT服务是否正常运行
2. 确认服务器地址和端口配置正确
3. 检查网络连接

### 问题2：工位测试失败

**错误信息**：`工位 XXXX 测试失败`

**解决方案**：
1. 查看详细错误日志
2. 检查设备状态
3. 验证设备配置是否正确

### 问题3：告警监控启动失败

**错误信息**：`告警监控启动失败`

**解决方案**：
1. 检查噪音传感器是否在线
2. 确认传感器IP地址和端口配置正确
3. 验证告警阈值设置

## 扩展开发

### 添加新的工位

1. 在`STATIONS_CONFIG`中添加工位配置
2. 在`PRODUCTION_LINE_SEQUENCE`中添加测试顺序
3. 定义测试步骤

### 添加新的测试步骤

在工位配置的`test_steps`数组中添加步骤定义：

```python
{
    "step_no": N,
    "name": "步骤名称",
    "description": "步骤描述",
    "expected_duration": 秒数,
    "action": "操作描述",
    "expected_result": "预期结果",
}
```
