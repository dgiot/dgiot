# 无人机测试产线 - 一键式端到端测试系统总结

## 项目概述

本项目实现了一个完整的一键式端到端测试系统，用于无人机测试产线的自动化测试。系统支持单个工位测试和完整产线测试，每个工位都有独立的测试场景和明确的测试步骤。

## 核心设计理念

### 1. 每个工位一个场景
每个工位都有独立的测试场景配置，包含：
- 工位基本信息（ID、名称、IP、设备组合）
- 测试步骤（步骤名称、描述、预计耗时、操作、预期结果）
- PLC配置（基地址、IP地址）

### 2. 端口即设备类型
通过端口号自动识别设备类型，简化设备管理：
- 10001-10005: 舵面传感器
- 10006: 单片机（治具）
- 10007: 无人机地测口
- 1234: 扫码枪
- 21000: 噪音传感器

### 3. 端到端测试流程
从扫码开始到报告生成的完整流程：
```
扫码启动 → 设备绑定 → 工位测试 → 报告生成
```

### 4. 噪音全程监控
1700告警检测工位全程监控产线噪音：
- 2个噪音传感器实时监控
- 告警阈值：警告75dB，严重85dB
- 与产线测试同步进行

### 5. 详细测试报告
生成JSON和HTML格式的测试报告：
- 测试摘要（测试ID、时间、状态）
- 工位测试详情（每个工位的测试步骤和结果）
- 告警事件（噪音监控过程中记录的告警）

| 1100 | 桁架工位 | 192.168.100.51 | 10001-10007 | 舵面×5+单片机+地测口+无人机 | 3 | 基地址1100, IP 192.168.100.40 |
| 1700 | 告警检测工位 | - | 21000 | 噪音传感器×2 | 全程监控 | - |

### 测试流程顺序

完整产线测试顺序：**1200 → 1500 → 1600 → 1100**

1. **磁航向工位 (1200)** - 扫码绑定入口，磁航向校准测试
2. **总测工位 (1500)** - 10步测试流程，完整功能验证
3. **拷机工位 (1600)** - 舵面数据采集测试，拷机时长验证
4. **桁架工位 (1100)** - 桁架机械手测试，导引头功能验证

### 1700告警检测工位

- **功能**：全程监控产线噪音，不绑定具体工位
- **传感器**：2个噪音传感器（IP: 192.168.100.35/36, 端口: 21000）
- **告警阈值**：
  - 警告：75dB
  - 严重：85dB
- **监控时长**：与产线测试同步

## 测试步骤详情

### 1200 磁航向工位 (4步)

1. **扫码获取设备编码** (5秒)
   - 描述：扫码枪扫描设备编码(UAV-12345)，触发设备绑定
   - 操作：扫码枪发送: SCAN:UAV-12345
   - 预期结果：设备成功绑定到1200工位

2. **磁航向校准测试** (30秒)
   - 描述：测试磁航向传感器精度
   - 操作：发送遥控指令: F0 FB (舵面中位)
   - 预期结果：磁航向数据正常，校准完成

3. **磁场精度检测** (20秒)
   - 描述：检测磁场传感器的精度和稳定性
   - 操作：采集磁场数据
   - 预期结果：磁场误差 < 0.5°

4. **磁偏补偿测试** (25秒)
   - 描述：测试磁偏角补偿功能
   - 操作：发送飞行指令，验证磁偏补偿
   - 预期结果：航向角准确，补偿正常

### 1500 总测工位 (10步)

1. **备检并获取编码** (5秒)
   - 描述：通过扫码获取设备编码，准备测试
   - 操作：扫码枪扫描设备编码
   - 预期结果：获取到设备编码 UAV-12345

2. **机身静态测试前检查** (10秒)
   - 描述：检查机身完整性、螺旋桨安装情况
   - 操作：视觉检查，确认机身无损伤
   - 预期结果：机身完好，螺旋桨安装正确

3. **机身及螺旋桨安装情况检查** (15秒)
   - 描述：详细检查螺旋桨安装是否牢固、方向正确
   - 操作：手动检查所有螺旋桨
   - 预期结果：所有螺旋桨安装牢固，方向正确

4. **电压测量检查** (10秒)
   - 描述：测量电池电压，确保电量充足
   - 操作：单片机上报电压数据
   - 预期结果：电池电压在 22.2V - 25.2V 范围内

5. **链路功能检查** (20秒)
   - 描述：测试地面站与无人机之间的通信链路
   - 操作：地面站发送心跳指令，无人机应答
   - 预期结果：链路通信正常，延迟 < 100ms

6. **上电参数检查** (15秒)
   - 描述：检查上电后的各项参数设置
   - 操作：读取无人机配置参数
   - 预期结果：所有参数符合设计要求

7. **夜航灯测试** (10秒)
   - 描述：测试夜航灯的亮灭和颜色
   - 操作：发送夜航灯控制指令
   - 预期结果：夜航灯正常亮灭，颜色正确

8. **气压高度检测** (15秒)
   - 描述：测试气压高度传感器的精度
   - 操作：改变气压，验证高度读数
   - 预期结果：高度误差 < 0.5m

9. **系统电磁兼容性功能检查** (20秒)
   - 描述：测试系统在电磁干扰环境下的稳定性
   - 操作：施加电磁干扰，验证系统稳定性
   - 预期结果：系统运行稳定，无异常

10. **航线加载及载荷功能检查** (30秒)
    - 描述：测试航线加载和载荷功能
    - 操作：加载测试航线，验证载荷响应
    - 预期结果：航线加载成功，载荷功能正常

### 1600 拷机工位 (4步)

1. **拷机前检查** (10秒)
   - 描述：检查设备状态，准备拷机
   - 操作：检查所有舵面传感器和单片机状态
   - 预期结果：所有设备正常，准备就绪

2. **舵面数据采集测试** (120秒)
   - 描述：采集5个舵面的偏转数据
   - 操作：发送舵面偏转指令，采集传感器数据
   - 预期结果：舵面偏转数据准确，响应正常

3. **导引头功能测试** (30秒)
   - 描述：测试导引头的功能和精度
   - 操作：发送导引头控制指令，验证响应
   - 预期结果：导引头响应准确，功能正常

4. **拷机时长验证** (10秒)
   - 描述：验证拷机时长是否符合要求
   - 操作：记录拷机开始和结束时间
   - 预期结果：拷机时长在规定范围内

### 1100 桁架工位 (3步)

1. **桁架机械手测试** (20秒)
   - 描述：测试桁架机械手的动作精度
   - 操作：控制桁架机械手执行预定动作
   - 预期结果：机械手动作准确，精度符合要求

2. **舵面机械臂测试** (20秒)
   - 描述：测试舵面机械臂的功能
   - 操作：控制舵面机械臂执行测试动作
   - 预期结果：机械臂动作正常，响应及时

3. **导引头功能验证** (30秒)
   - 描述：验证导引头在桁架环境下的功能
   - 操作：发送导引头指令，验证桁架环境下的响应
   - 预期结果：导引头功能正常，符合设计要求
