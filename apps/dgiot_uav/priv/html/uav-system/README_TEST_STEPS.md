# 测试项编排系统使用说明

## 概述

测试项编排系统提供了一个可视化的界面，用于管理超近距无人机自动检测系统的测试步骤。

## 访问地址

```
http://127.0.0.1/uav-system/test-steps.html
```

## 功能特点

### 1. 测试步骤管理
- ✅ 新增测试步骤
- ✅ 编辑测试步骤
- ✅ 删除测试步骤
- ✅ 步骤排序（上移/下移）
- ✅ 步骤状态控制（启用/禁用）

### 2. 步骤字段说明

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 步骤序号 | 步骤的执行顺序 | 是 | 1, 2, 3... |
| 步骤类型 | 步骤的操作类型 | 是 | 发送、接收、操作、判断、等待 |
| 描述 | 步骤的详细描述 | 是 | 自动测试系统软件向MES发送"总测开始"相关数据 |
| 目标设备 | 步骤操作的目标设备 | 否 | MES、PLC、无人机、扫码枪、传感器、治具、— |
| 指令号 | 具体的指令编号 | 否 | F045、D1100 |
| 指令名称 | 指令的可读名称 | 否 | 复飞命令、动力使能开 |
| 延时(秒) | 执行完该步骤后的等待时间 | 否 | 2、0.5 |
| 状态 | 步骤是否启用 | 是 | 启用、禁用 |
| 指标数 | 该步骤包含的指标数量 | 否 | 3、0 |
| 所属工位 | 步骤所属的工位类型 | 是 | 磁航向、总测、动力检测、拷机、桁架、通用 |

### 3. 步骤类型说明

- **发送**: 向目标设备发送指令或数据
- **接收**: 从目标设备接收数据或响应
- **操作**: 执行某种操作（如扫码、上电等）
- **判断**: 根据条件判断测试结果
- **等待**: 等待指定时间后继续

### 4. 操作按钮

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 上移 | 将步骤向上移动一位 | ↑ |
| 下移 | 将步骤向下移动一位 | ↓ |
| 编辑 | 编辑该步骤的详细信息 | E |
| 测试 | 单独测试该步骤 | T |
| 删除 | 删除该步骤 | Del |

### 5. 工位过滤

可以通过顶部的工位下拉框过滤特定工位的测试步骤：
- 所有工位
- 磁航向
- 总测
- 动力检测
- 拷机
- 桁架

### 6. 导出功能

点击右上角的"导出"按钮，可以将当前所有测试步骤导出为JSON文件。

## 数据存储

测试步骤数据存储在工位产品的`content.test_steps`字段中。

### 产品ID
```javascript
const PRODUCTS = {
    uav: '6235befb62',       // 超近距无人机
    fixture: 'bd49cc8272',   // 超近距无人机治具
    station: '343cf21f82'    // 工位产品(设备)
};
```

### API路径
```
PUT /api/unified/iot/classes/Product/{productId}
```

### 请求体
```json
{
  "content": {
    "test_steps": [...]
  }
}
```

## 故障排查

### 1. 页面无法打开
- 检查DG-IoT服务是否正常运行
- 检查文件路径是否正确
- 检查Nginx配置是否正确

### 2. 数据加载失败
- 检查产品ID是否正确
- 检查API路径是否正确
- 查看浏览器控制台错误信息

### 3. 保存失败
- 检查必填字段是否都已填写
- 检查网络连接是否正常
- 查看DG-IoT日志

## 开发说明

### 修改产品ID
编辑`test-steps.html`文件中的`PRODUCTS`常量：

```javascript
const PRODUCTS = {
    uav: 'your_uav_product_id',
    fixture: 'your_fixture_product_id',
    station: 'your_station_product_id'
};
```

### 修改API路径
编辑`API_BASE`常量：

```javascript
const API_BASE = '/api/unified/iot';
```

### 自定义字段
可以在弹窗中添加自定义字段，并更新`saveStep()`函数。
