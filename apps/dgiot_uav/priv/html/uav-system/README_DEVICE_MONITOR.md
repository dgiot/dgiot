# 设备监控系统使用说明

## 概述

设备监控系统提供了一个实时、紧凑的四列布局界面，用于监控超近距无人机自动检测系统的所有通信通道和设备状态。

## 访问地址

```
http://127.0.0.1/uav-system/device-monitor.html
```

## 界面布局

### 四列网格布局

页面采用响应式四列网格布局，每列显示一个设备卡片：

| 列 | 内容 | 说明 |
|----|------|------|
| 列1 | 通道卡片1 | 超近距无人机UDP多播采集通道 |
| 列2 | 通道卡片2 | 超近距无人机调度通道 |
| 列3 | 通道卡片3 | 超近距无人机PLC控制通道 |
| 列4 | 工位卡片N | 各工位设备列表 |

### 卡片类型

#### 1. 通道卡片

显示通信通道的详细信息：

**卡片内容包括：**
- **通道名称**: 完整的通道名称
- **通道ID**: 缩短的ID标识（前8位）
- **协议类型**: UAV_UDP, UAV_TCP, UAVPLCC
- **地址信息**: IP地址和端口号
- **端点类型**: 设备端/通道端
- **状态指示**: 在线/离线

**示例：**
```
超近距无人机UDP多播采集通道
协议: UAV_UDP
地址: 192.168.100.100:8001
端点: 通道端
状态: ✓ 在线
```

#### 2. 工位卡片

显示工位及其所属设备的详细信息：

**卡片内容包括：**
- **工位名称**: 磁航向工位、总测1工位、总测2工位等
- **设备数量**: 该工位下的设备总数
- **设备列表**: 每个设备的详细信息

## 设备信息展示

### 设备项格式

每个设备项包含以下信息：

```
┌─────────────────────────────────────┐
│ ● 无人机(UAV) [地测口] [设备端] │  ← 设备名称、类型、端点
│   192.168.100.21:10007           │  ← 网络地址
│   [Modbus TCP] ● 在线             │  ← 协议、状态
└─────────────────────────────────────┘
```

### 设备字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 状态指示灯 | ● 在线 / ○ 离线 | 绿色/红色 |
| 设备名称 | 设备的完整名称 | 无人机(UAV) |
| 设备类型 | 设备的类型分类 | 地测口、Modbus TCP、治具 |
| 端点类型 | 设备端/通道端 | 设备端、通道端 |
| 网络地址 | IP地址:端口 | 192.168.100.21:10007 |
| PLC地址 | Modbus寄存器地址 | D1700、D1500 |
| 协议 | 通信协议类型 | TCP、UDP、Modbus TCP |
| 状态文字 | 在线/离线 | 在线 |

### 特殊设备展示

#### 治具设备（带子设备）

治具设备包含多个子设备，以缩进形式展示：

```
治具设备 [治具]
  [10001] 左前翼舵面
  [10002] 右前翼舵面
  [10003] 左侧翼舵面
  [10004] 右侧翼舵面
  [10005] 治具基准舵面
  [10006] 单片机
```

#### PLC设备（带地址）

```
PLC-D1500 [Modbus TCP] [通道端]
  192.168.100.40:502
  D1500
```

## 功能操作

### 1. 自动刷新

- **刷新间隔**: 30秒
- **自动执行**: 页面加载后自动开始
- **时间显示**: 页面右上角显示最后更新时间

### 2. 手动刷新

点击页面右上角的"刷新"按钮，立即刷新所有设备状态。

### 3. 实时状态

- **在线设备**: 绿色指示灯 + "在线"文字
- **离线设备**: 红色指示灯 + "离线"文字

## 响应式设计

### 屏幕适配

- **大屏幕 (≥1200px)**: 4列布局
- **中屏幕 (900-1199px)**: 3列布局
- **小屏幕 (600-899px)**: 2列布局
- **超小屏幕 (<600px)**: 1列布局

## 性能优化

### 自动刷新策略

- **刷新间隔**: 30秒
- **刷新方式**: 部分更新（仅更新状态）
- **缓存机制**: 本地缓存静态数据

### 加载优化

- **首次加载**: 显示加载动画
- **数据获取**: 使用静态数据（可切换为API）
- **渲染优化**: 批量DOM更新

## 故障排查

### 1. 页面无法打开

- 检查DG-IoT服务是否正常运行
- 检查文件路径是否正确
- 检查浏览器控制台错误

### 2. 数据不更新

- 检查网络连接
- 点击"刷新"按钮手动刷新
- 检查API路径是否正确

### 3. 设备状态显示异常

- 检查设备实际连接状态
- 查看DG-IoT日志
- 检查通道配置是否正确

## 扩展开发

### 添加新通道

在`CHANNELS`对象中添加配置：

```javascript
const CHANNELS = {
    new_channel: {
        name: '新通道名称',
        protocol: 'PROTOCOL',
        address: '192.168.100.100:XXXX',
        endpoint: '通道端',
        id: 'xxxxxxxx'
    }
};
```

### 添加新工位

在`STATIONS`对象中添加配置：

```javascript
const STATIONS = {
    '新工位': {
        devices: [
            {
                name: '设备名称',
                type: '设备类型',
                address: 'IP:PORT',
                protocol: '协议',
                endpoint: '设备端',
                status: 'online'
            }
        ]
    }
};
```

### 接入实时API

替换`loadAllDevices()`函数中的静态数据获取：

```javascript
async function loadAllDevices() {
    // 从API获取实时数据
    const resp = await fetch(`${API_BASE}/devices/all`);
    const data = await resp.json();
    // 更新设备状态
}
```
