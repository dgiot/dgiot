## 🚀 使用方法

### 方式1: 使用快速启动菜单（推荐）

```bash
cd apps/dgiot_uav/priv/scripts/simulators
./run_production_line.sh
```

**菜单选项**:
1. 测试单个工位
2. 测试指定产线
3. 测试所有产线
4. 测试多个工位
5. 启用MES集成测试
6. 查看测试日志

### 方式2: 直接使用Python脚本

```bash
# 测试单个工位
python3 production_line_runner.py --station 1500

# 测试多个工位
python3 production_line_runner.py --stations 1500,1600,1700

# 测试产线A
python3 production_line_runner.py --line 1

# 测试所有产线
python3 production_line_runner.py --all

# 启用MES集成
python3 production_line_runner.py --all --mes
```

## 📊 工位配置

| 工位ID | 工位名称 | 基地址 | 测试命令数 | 模拟器类型 |
|--------|---------|--------|-----------|-----------|
| 1100 | 桁架机械手工位 | D1100 | 6 | PLC |
| 1200 | 拷机工位1 | D1200 | 1 | 治具 |
| 1300 | 拷机工位2 | D1300 | 1 | 治具 |
| 1500 | 总测工位1 | D1500 | 16 | 无人机+治具 |
| 1600 | 总测工位2 | D1600 | 16 | 无人机+治具 |
| 1700 | 磁航向工位 | D1751 | 5 | 无人机 |

### 产线路径

**产线A**: 1100(桁架) → 1500(总测1) → 1200(拷机1)

**产线B**: 1600(总测2) → 1300(拷机2) → 1700(磁航向)

## 📡 MES集成

### 消息类型

1. **test_start**: 测试开始消息
2. **command_executed**: 命令执行消息
3. **test_complete**: 测试完成消息
4. **test_failed**: 测试失败消息
5. **line_test_start**: 产线测试开始
6. **line_test_complete**: 产线测试完成

### 使用示例

```bash
# 启用MES集成测试
python3 production_line_runner.py --all --mes

# 自定义MES服务URL
python3 production_line_runner.py --all --mes --mes-url http://your-mes:8080/api
```
