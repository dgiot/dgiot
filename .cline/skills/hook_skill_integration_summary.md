# 技能与Hook系统高级联动集成总结

- **位置**: `.clinerules/hooks/SkillActivation`

- **关键词映射**: 建立了关键词到技能的映射关系，支持自动检测

## 技能-Hook联动机制

### 自动技能检测流程
1. **TaskStart阶段**: 分析用户消息，检测关键词，推荐相关技能
2. **UserPromptSubmit阶段**: 实时检测技能需求
3. **PreToolUse阶段**: 检查工具使用是否需要特定技能支持

### 技能分类体系
1. **核心技能**: Erlang中文UTF8、包含系统、日志解决方案等
2. **领域技能**: DGIOT产品管理、设备管理、通道管理等
3. **工具技能**: 无人机协议分析、时序存储、测试界面等
4. **管理技能**: 技能管理、Hook管理、主目标跟踪等

### 关键词映射示例
- "中文打印" → `erlang_chinese_utf8`
- "通道" → `dgiot_core_concepts`
- "tdengine" → `dgiot_data_storage`
- "编译" → `dgiot_compile_debug`
- "无人机" → `uav_protocol_analyzer`
- "技能" → `skill_manager`
- "hook" → `hook_manager`
